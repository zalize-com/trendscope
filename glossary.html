glossary

Every term this site uses, defined once — each links to the page and API where it lives.

board

The daily leaderboard: top items from all tracked sources, merged and scored. Items are ranked by a per-source score scaled to a comparable range.

index.html· latest.json

score

Each item's ranking signal as reported by its source — points, comments, or feed position ("feed rank"). Scores are normalized per source so different communities compare fairly.

data dictionary

source

A tracked community or feed (27 of them): news sites, blogs, aggregators, package registries. Each uses its own fetcher in scripts/collect.py.

about.html· sources.json

fresh / new

Items on today's board that were not on yesterday's — newly arrived. The reverse of "gone".

new.html· new.json

gone

Items on yesterday's board that dropped off today's — churned out. The exit side of the board.

gone.html· gone.json

riser

An item still on the board whose rank improved day-over-day. The reverse of "faller".

risers.html· risers.json

faller

An item still on the board whose rank dropped day-over-day. Falling, but not yet gone.

risers.html· risers.json

meteor

An item with the biggest single-day score spike — the fastest climbers, even mid-rank.

meteors.html· series.json

veteran / board veteran

An item with the longest streak of consecutive days on the board — staying power, not spike.

oldest.html· streaks.json

streak

Consecutive days an item has appeared on the board. Streaks drive veterans and the longest_all_time list.

streaks.html· streaks.json

crossover

An item appearing on multiple sources' boards the same day — a story that crossed communities.

crossovers.html· crossovers.json

spike

An unusual single-day volume jump for a source — more items than its weekday baseline suggests.

weekday.json

topic

A keyword bucket (AI/LLM, Web Dev, Security, …) classifying items by title/url. Cheap heuristic, good for slicing.

topics.html· topics.json

snapshot

The frozen daily board: data/daily/YYYY-MM-DD.json. Everything historical derives from snapshots.

datasets.html

embed

A self-contained widget page (embed.html?mode=…) you iframe anywhere — 25 modes, one per view.

embeds.html
