api clients

Copy-paste starters for the trendscope API — no keys, no signup, plain JSON. Base: https://zalize-com.github.io/trendscope.

curl

BASE=https://zalize-com.github.io/trendscope
curl -s $BASE/data/latest.json | python3 -m json.tool | head -40
curl -s $BASE/docs/api/new.json      # today's fresh items
curl -s $BASE/docs/api/meteors.json  # biggest 1-day climbers
curl -s $BASE/docs/api/streaks.json  # board veterans
curl -s $BASE/docs/api/meta.json     # machine-readable catalog

python (stdlib only)

import json, urllib.request
BASE = "https://zalize-com.github.io/trendscope"
latest = json.load(urllib.request.urlopen(BASE + "/data/latest.json"))
items = [i for v in latest["items"].values() for i in v] if isinstance(latest.get("items"), dict) else latest["items"]
for it in items[:10]:
    print(it["rank"], it["title"], it["url"])

javascript / browser

const BASE = "https://zalize-com.github.io/trendscope";
const latest = await (await fetch(BASE + "/data/latest.json")).json();
const items = Object.values(latest.items).flat(); // dict-of-lists or list
console.table(items.slice(0, 10));
