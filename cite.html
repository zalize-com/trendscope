What to cite

  • The dataset — data/latest.json, history.csv, data/daily/ (per-day snapshots).
  • The API surface — 23 endpoints under docs/api/ (docs).
  • The HN canons — 19 years of monthly top stories / Show HN / Ask HN (canon), 15 years of hiring-thread counts (hiring).
  • The software — MIT-licensed collectors + static dashboard at the repo.

Provenance

  • Every record carries url, captured_at, source and rank.
  • Snapshots run twice daily via GitHub Actions — see data/index.json for the full edition list.
  • Per-source item counts and latency: health.json / health page.
