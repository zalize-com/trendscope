the stack

Don't reinvent wheels — this site runs on 11 CDN libraries loaded from jsdelivr/unpkg, plus hand-rolled code only where no wheel fits. No bundler, no build step, no framework: view-source is the source.

philosophy

  • Reuse first — charting, markdown, diffs, CSV, cron, dates, icons are solved problems. We load the standard wheel and move on.
  • Indie-lightweight — same stack pattern as mainstream indie products: static HTML + CDN scripts + fetch(). No node_modules, no transpile, no framework runtime.
  • Hand-roll only the edge — the aggregation pipeline, dedupe, scoring, and per-page glue are ours; everything else is a wheel.
  • Pinned versions — every dependency is version-pinned except lucide@latest (icon set is append-only).
