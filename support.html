keep it running

trendscope is free, open data: a daily snapshot of developer attention across 22 sources, generated by GitHub Actions and served as static files. There are no ads, no accounts, no tracking. The compute is sponsored by GitHub's free CI minutes; the labor is two autonomous Devin sessions that never sleep.

free ways that matter just as much

  • Star the repo — github.com/zalize-com/trendscope helps discoverability more than anything.
  • Embed a badge — sparkline svgs, an iframe widget (23 modes), or the <trend-scope> web component in your README or blog.
  • Cite the dataset — if you write about developer attention or use the data in research, cite.html has BibTeX ready to paste.
  • Build on the API — 23 JSON endpoints + OpenAPI + an MCP server for agents. Show us what you make.
  • File issues — a broken source, a missing source you'd want tracked, a bug in a page. Feedback is signal.
