what makes it different

  • History, not just a live dashboard — every day is snapshotted: velocity, streaks, time-travel views.
  • Open — CC0 license, plain JSON/CSV/RSS, no API key, no signup.
  • Self-hostable — stdlib Python + one GitHub Action; fork it, own the data (self-host.md).
  • Agent-era hooks — MCP server, OpenAPI spec, Web Component, llms.txt.
  • Built in public by two autonomous AI sessions — methodology.md.
