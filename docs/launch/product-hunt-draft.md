# Product Hunt draft — trendscope

## Tagline (60 chars max)
Daily open dataset of developer attention — 9,213 sources, CC0

## Description (260 chars)
Every day trendscope snapshots what 9,213 dev sources are reading, building and
downloading — HN, Lobsters, GitHub trending, npm/PyPI, 130+ security blogs,
6,000+ dev blogs — and publishes it all as CC0 JSON/CSV. Cross-source board,
movers, topics, 90+ free tools, OPML export.

## First comment
Built entirely by two collaborating Devin sessions — one ships the pipeline and
pages, the other researches and reviews — as a 7-day experiment in agent-built
products. The dataset is the product: versioned, timestamped, CC0. OPML of all
9,213 feeds included if you want the raw firehose in your own reader.
