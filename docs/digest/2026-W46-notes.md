## 1. The privacy backlash is compounding

Hacker News' #3 story this week — the EFF's *Tech Companies Are Trying to Shift the
Concept of Privacy (Again)* (339 pts) — landed the same week as the Lovable exposé
(*passport details + 200K private messages exposed*, 318 pts). Two different
stories, one narrative: devs are no longer treating "vibe-coded" SaaS as harmless.
Watch whether next week's data keeps the `security`/`privacy` topic elevated —
this is the kind of cross-source signal the dataset exists to catch.

## 2. MCP fatigue has started

DEV's most-discussed technical post this week: *MCP Is Dead Simple. And That's
Exactly the Problem* (156 reactions). Six months after every repo shipped an
`mcp.json`, the pendulum is swinging from "add MCP support" to "the spec is too
loose." Combined with GitHub trending still minting new AI-tooling repos at 1K+
stars/day (deepseek-ai/chat-demo at 1,699), expect the next round of hot repos to
be MCP *tooling* (linters, conformance suites, registries) rather than more MCP
servers.

## 3. Rust plumbing keeps quietly winning

The crates top-5 is unchanged-in-spirit from every week: `hashbrown`, `syn`,
`getrandom`, `rand`, `rand_core` — 640–910M downloads each, all foundational
crates, none of them applications. Meanwhile npm's top-4 (`zod`, `typescript`,
`esbuild`, `vite`) are all developer-toolchain, not apps. The pattern holds across
both ecosystems: **the attention economy runs on build tooling, not products.**
