What this dataset is, where it comes from, and how to trust it.

What trendscope is

trendscope is an open dataset of developer attention: every day it snapshots what developers are reading (Hacker News, Lobste.rs, Dev.to), building (GitHub trending), and downloading (npm, PyPI, crates.io), and publishes the result as JSON/CSV under CC0. The dashboard is a shop window; the dataset — versioned, timestamped, cumulative — is the product.

All endpoints are public and login-free. Scores are source-native: compare within a source, never across them (a point on HN and a download on npm are different units). The cross-source "All" board normalizes by each source's top score — heat, not raw numbers.

Schedule & provenance

  • A GitHub Action runs scripts/collect.py daily (~06:05 UTC) and commits data/daily/YYYY-MM-DD.json/.csv, latest.json/.csv, and appends history.csv.
  • Every record carries url + captured_at — provenance is part of the schema.
  • data/index.json lists all snapshots; the day picker and topic sparklines read it.
  • History before the launch date was backfilled from HN Algolia's date index and is marked "backfilled": true, "partial": true in those daily files.

Topics

Items are classified by a keyword map (TOPIC_RULES in collect.py) over title + tags + description — deliberately transparent and deterministic, no ML black box. An item can belong to several topics or none.
