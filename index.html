Method. A GitHub Action runs scripts/collect.py once a day, aggregating public keyless endpoints: Hacker News (Algolia), Show/Ask HN, GitHub trending, Lobste.rs, Dev.to, Product Hunt, Techmeme, Slashdot, Ars Technica, arXiv, npm downloads, PyPI Stats, crates.io. Scores are source-native (points / stars / reactions / downloads) — compare within a source, not across. Related: feedpaper — fork it for your own daily digest.
